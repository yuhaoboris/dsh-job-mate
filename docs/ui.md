# 界面交付与验证

首次使用从简历开始，后续通过工作台检查进展并处理待决定事项。界面沿用宿主字体和明暗主题。职伴品牌色取自上游 `job-mate/assets/branding/README.md`。薄荷绿用于筛选职位和简历首屏，淡黄绿用于查看 HR 消息，鲜绿用于主按钮。品牌渐变用于工作台标题图标、简历图标和插件图标。深色任务卡片使用对应的深底浅字。等待、待核对和失败状态使用蓝、琥珀和红，并配有文字。任务卡片的留白、双色图标和悬停反馈参考了 [Open Artifacts 的作品页](https://github.com/JimLiu/open-artifacts/blob/main/dsh-plugins/dsh-claude-artifacts/lib/client.js)。

| 场景 | 预期 |
|---|---|
| 首次使用 | 简历选择、支持格式、下一步用途清晰，无基础资料表单 |
| 简历已上传 | 显示文件名，进入对话确认，不要求再次提供 |
| 上传失败/扫描件 | 明确失败，保留选择与旧资料，不把不完整文本保存为事实 |
| 已配置零记录 | 有筛选与查看消息入口，说明记录何时出现 |
| 有记录 | 按状态筛选或搜索公司和职位，可清除筛选。记录原地展开，展示完整历史、原文与证据 |
| 待决定 | 当前问题与目标，点击打开待发送的会话草稿 |
| 发送不明 | 独立标记，提示先核对，不显示成等待回复 |
| 加载失败 | 保留并标明旧快照，禁用任务入口；可重试 |
| 认证失效 | 隐藏旧私人资料 |
| 运行/暂停 | 显示状态，可暂停后续操作；说明不撤回已发消息 |
| 窄屏/长文本 | 按插件面板宽度布局。760px 以下记录与待办上下排列，440px 以下任务卡片单列。长公司名和历史原文可换行 |

语义与键盘：使用原生 button/input/select/details；显式搜索和筛选 label；文件输入有可见 label；焦点有轮廓；错误 role=alert、状态 role=status，禁用状态保留文字。界面中文，时间按浏览器 Locale 显示，时区来自系统；不宣称已完成其他语言本地化或屏幕阅读器真机认证。

实际验证以测试结果和隔离 Harness 检查为准，不把此清单本身当作通过证据。更新主题时需再次检查深色、焦点和正文对比。

## 插件更新

侧栏在工作台未打开时也会检查版本；展开侧栏显示「有更新 / 更新中 / 更新失败 / 待重启」，收起侧栏用带可访问名称的圆点表示。日常版本信息和检查入口在页底展开。有新版本、更新中、失败或待重启时，相关操作和可滚动的纯文本发布日志显示在页首。

| 场景 | 预期 |
|---|---|
| 有稳定新版本 | 侧栏提示；打开职伴可阅读日志并主动更新 |
| 正在更新 | 禁用重复安装及新的工作台任务入口；状态保留在侧栏 |
| 安装成功待重启 | 明确要求退出并重新打开 DSH；刷新页面后仍可识别 |
| 检查/安装失败 | 不声称成功；显示错误和检查/重试入口 |
| 本地源码安装 | 可查看新版本与日志，提示通过 DSH 插件管理安装 GitHub 版本 |
| 正在求职 | 禁用更新；Host 也拒绝安装 |
| 没有新版本 | 显示当前版本和检查入口；日志可展开 |

交互参考 [baoyu-design 的 DSH 插件](https://github.com/JimLiu/baoyu-design/tree/main/dsh-plugins/dsh-claude-artifacts)，本项目独立实现；未复制其代码或视觉资产。宿主安装语义以 [Plugin Manager types](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/boot/plugin-manager/src/types.ts) 为准。
