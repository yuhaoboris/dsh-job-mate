# 界面交付与验证

目标：首次用户只提供简历；后续主要看进展和处理决定，不维护基础数据表单。界面采用宿主字体与主题 token，主操作深绿色，状态同时用文字表达；图标由本项目已有 SVG 复用，无外部字体或图片资产。

| 场景 | 预期 |
|---|---|
| 首次使用 | 简历选择、支持格式、下一步用途清晰，无基础资料表单 |
| 简历已上传 | 显示文件名，进入对话确认，不要求再次提供 |
| 上传失败/扫描件 | 明确失败，保留选择与旧资料，不把不完整文本保存为事实 |
| 已配置零记录 | 有筛选与查看消息入口，说明记录何时出现 |
| 有记录 | 状态筛选、公司/职位搜索、完整历史、原文与证据 |
| 待决定 | 当前问题与目标，点击打开待发送的会话草稿 |
| 发送不明 | 独立标记，提示先核对，不显示成等待回复 |
| 加载失败 | 保留并标明旧快照，禁用任务入口；可重试 |
| 认证失效 | 隐藏旧私人资料 |
| 运行/暂停 | 显示状态，可暂停后续操作；说明不撤回已发消息 |
| 窄屏/长文本 | 850px 以下单列；长公司名、历史原文可换行，不裁剪操作 |

语义与键盘：使用原生 button/input/select/details；显式搜索和筛选 label；文件输入有可见 label；焦点有轮廓；错误 role=alert、状态 role=status，禁用状态保留文字。界面中文，时间按浏览器 Locale 显示，时区来自系统；不宣称已完成其他语言本地化或屏幕阅读器真机认证。

实际验证以测试结果和隔离 Harness 检查为准，不把此清单本身当作通过证据。更新主题时需再次检查深色、焦点和正文对比。
